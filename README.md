# Gway POS — démo interactive / 互动演示

**Démo en ligne / 在线演示：** https://xubo-327.github.io/gway-demo/

## Français

Démonstration du logiciel de caisse **Gway POS** et de son **menu électronique** (le client scanne le QR code de la table, commande et paie ; la commande arrive à la caisse et en cuisine).

- Les écrans sont ceux du vrai logiciel (menu client, caisse, écran cuisine), pas des maquettes.
- **C'est une démo** : il n'y a pas de serveur. Un petit serveur simulé tourne dans votre navigateur (Service Worker) ; les données de démo restent **uniquement dans votre navigateur**. Recharger la page ou « Réinitialiser » remet tout à zéro.
- **Les données sont fictives** : les trois commerces (Jardin de Jade, Perle de Thé, Marché Soleil), les plats, les prix et les noms sont inventés.
- Les impressions sont simulées ; aucun paiement réel n'est possible.

## 中文

**Gway 收银系统** 和 **电子菜单** 的演示：顾客扫桌上二维码点单、付款，单子到收银台和后厨。

- 画面都是真实软件的界面（顾客点单页、收银台、后厨屏），不是效果图。
- **这只是演示**：没有服务器，浏览器里跑一个模拟的小服务器（Service Worker）；演示数据**只保存在你的浏览器里**，刷新页面或点「重置演示」就全部恢复。
- **数据都是虚构的**：三家店（Jardin de Jade、Perle de Thé、Marché Soleil）、菜品、价格、人名都是编的。
- 打印是模拟的，不能真的付款。
